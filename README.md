# MonopolyFunny

Ελληνικό παιχνίδι στρατηγικής ακινήτων για έναν άνθρωπο απέναντι σε 1–3 αντιπάλους AI. Πρωτότυπα ονόματα ακινήτων και απλοποιημένοι κανόνες.

## Χρήση

Ανοίξτε το index.html ή ενεργοποιήστε GitHub Pages (main / root). Τα δεδομένα αποθηκεύονται τοπικά στον browser. Δεν απαιτείται λογαριασμός ή Supabase.

## Περιλαμβάνει

Ταμπλό 40 θέσεων, ζάρια, ιδιοκτησίες, ενοίκια, δημοπρασίες, σπίτια, υποθήκες, κάρτες, φυλακή, χρεοκοπία, αυτόματη αποθήκευση και οδηγίες.

## Περιορισμοί πρώτης έκδοσης

Οι κανόνες είναι απλοποιημένοι: οι δημοπρασίες των AI είναι αυτόματες, δεν υπάρχουν ανταλλαγές ακινήτων, η διαχείριση κτιρίων δεν περιλαμβάνει περιορισμένο απόθεμα και η εγκατάσταση PWA δεν παρέχει ακόμη εγγυημένη offline χρήση. Απαιτούνται δοκιμές πραγματικού browser πριν χαρακτηριστεί τελική έκδοση.
